## Findings considered and rejected

- **The absolute `/private/var/folders/...` path under page titles**: an artifact of the e2e fixture's temporary `HOME`. Real installs show `~/.dark-matter` because `routes/library.tsx:24` already uses `tildify`.
- **Changing the base font size away from 13px**: 13px is the macOS system UI size and the right body size for a native-feeling desktop app. The problem is the sizes _around_ it, which plan 001 fixes.

## Follow-ups noted in review

- From 005: `RowText`'s title line doesn't wrap, so a row with a long title plus several chips truncates the title, and chips can overflow on a narrow row. Before 005, `project-skills.tsx` and `skill-projects.tsx` let chips wrap. Watch at narrow widths; if it shows up, let the chips wrap onto a second line instead.
